# 来源筛选归零：真实链路修复与验收

2026-10-03。本次针对用户再次报告“参考资料与说明没有来源”。上一轮合成来源及局部真实模型测试没有覆盖真实检索，不能据此认定患者使用链路已经修复。

## 已证实原因

运行容器日志：知识库返回10条，外部可信规则保留4条，报告最终可追溯来源为0，同时相关性评估降级为词匹配。这里不是检索没有资料，而是筛选丢掉资料。

程序把查询词覆盖率 `命中词数/查询词数` 与语义模型的相关性分共用 `0.25` 阈值。查询包含多个症状和既往史时，某篇相关资料通常只覆盖其中一部分，因此分数被查询长度稀释。工具内筛一次，报告入口又按同一口径筛一次。另发现直接诊断入口只运行分析并清空模型自报来源，没有挂接实际检索来源。

## 修改

1. `backend/app/services/knowledge_citations.py`：语义分仍使用配置阈值；词匹配降级按真实主题词命中排序，排除零命中，不套用语义阈值。缓存再筛选也遵守相同规则；明确标注方法、命中词及局限，不把词覆盖率写成临床概率。
2. `backend/app/services/rag.py`：重排返回空、重复、越界或非有限分数时保留已召回片段，继续后续统一相关性判断；不把供应商损坏响应伪装成知识库为空。
3. `backend/app/services/agents.py`：完整问诊及直接诊断入口共享实际来源获取；没有来源不调用报告生成，有资料但正文没有有效编号引用也不发布。完整工作流只在引用检查后保存最终报告，避免先保存无来源的中间结果。
4. `backend/app/services/llm_errors.py` 与 `api/v1/agents.py`：错误码 `MEDICAL_EVIDENCE_UNAVAILABLE`，SSE明确说明本次未生成报告，直接HTTP入口返回503；已完成问诊但没有有据报告允许重试检索。
5. `frontend/src/components/ChatPage.tsx`：续答收到错误后重新开放当前题卡，保留会话用于重试。新增真实产物浏览器验证。不放行不可信外部，不造来源，不修改数据库设置/结构。

全局构建还发现并行新增的三个医生咨询组件使用不兼容的 Typography `fontWeight` 属性，已仅迁入 `sx`，保留原业务及样式：`ConsultationDetailPanel.tsx`、`ConsultationSharedRecord.tsx`、`patient/pages/ConsultationsPage.tsx`。原文件快照保留，恢复时只撤销这几个属性片段。

## 可复跑命令

从项目根目录执行，两个终端分别启动测试前端与验证。需要已配置模型的本地 `medaxis-backend` 才能复跑真实探针；探针会发模型/检索请求，但事务只读。不要输出容器环境或凭证。

```powershell
# 终端一
Set-Location D:\CAI-Projects\medaxis\frontend
npm run dev -- --host 127.0.0.1 --port 3011 --strictPort

# 终端二：本地保存的真实产物及定向回归

$env:PYTHONIOENCODING='utf-8'
python .ai/tasks/2026-10-03-source-empty-runtime/verify.py

# 独立只读探针，输出须保存到新文件，不能覆盖之前证据
Get-Content -Raw .ai/tasks/2026-10-03-source-empty-runtime/probe_retrieval.py | docker exec -i medaxis-backend python -
Get-Content -Raw .ai/tasks/2026-10-03-source-empty-runtime/probe_report.py | docker exec -i medaxis-backend python -
```

任务目录位于本地忽略目录，不随Git分发。新环境需提供合成真实产物或先跑真实探针；stdout含应用日志，应读取以 `{"scope"` 开头的JSON行。验证日志 `final-*.txt` 与截图保留。构建仍有既有大chunk提示，不宣称性能改善。

## 用户验收与运行生效

本地源码及独立测试进程已经验证。运行后端不使用自动reload，修改文件不会改变已加载模块；**现有后端需要重启才能应用修复**。前端错误题卡重试也需要使用最新构建或开发服务。现有历史报告不会因为改代码自动重算，不能把刷新旧报告当成新检索。

1. 后端加载新版后，新建合成腹泻问诊；完成采集后展开“参考资料与说明”：能看到来源名称、内部/外部类型、方法与原文，正文编号能打开同编号资料。不能以只看到“有10条来源”替代逐条资料。
2. 在隔离测试中模拟无来源/检索超时：显示明确检索错误，不生成成功报告、不保存无来源中间结果。恢复检索后点击当前题卡重试，应能继续同一会话。
3. 保留原病史及报告记录，对照原先零来源截图和新版来源原文。旧报告若缺原检索记录，重新检索/问诊获取新有据报告，不凭空给旧医学结论填引用。

运行态重启须遵守用户的“不要终止非当前任务启动进程”规则，需要用户授权具体本地服务；本轮不自动重启现有容器，不删除数据卷，不做迁移/远程部署。快照 `baseline/` 与manifest用于逐段恢复本轮修改，保留其他任务，禁止整仓覆盖。
