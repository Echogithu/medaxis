## 通俗的验收标准

| 要看什么 | 应当发生什么 |
|---|---|
| 资料确实相关 | 不能因共享“需要、治疗、时间”等泛词，把无关资料保留下来 |
| 命中的内容不完整 | 从同一文档相邻片段补前后文，保留命中片段；无法唯一定位则保留原来源 |
| 引用能追溯 | 来源标题、编号、完整摘录和内部文档/片段定位仍能查看，保存后重开也保留 |
| 没有对应资料 | 如实显示没有来源，不给无关来源凑数，也不编造网址或正文编号 |
| 版本不对应 | 请求2027新发布版，旧版本不能冒充该版本；出生年份不当作资料版本 |
