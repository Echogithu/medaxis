## 历史真实模型探测：题量下降含提前结束，不能算收益

修改前与最终修改后各运行一次相同 3 个合成状态：档案信息复用、未知答案复用、主诉信息复用。通过当前 web 模型配置使用 `deepseek-flash`；仅模型配置查询，数据库事务只读、结束回滚，不查询真实患者，不执行知识库/外部检索或持久化。每例最多 3 次模型调用。本组只是下一步决策探测，不是完整多轮问诊。

| 指标 | 之前 | 最终之后 | 变化 |
|---|---:|---:|---|
| 成功观测场景 | 3/3 | 3/3 | 无缺失场景 |
| 实际发出卡片 | 6 | 2 | −66.7% |
| 已记录维度重问 | 2 | 0 | 减少 2 次 |
| 模型调用数 | 4 | 4 | 不变 |
| Prompt Token | 1,679 | 2,781 | 增加 |
| Completion Token | 1,244 | 1,478 | 增加 |
| 总 Token | 2,923 | 4,259 | **+45.7%** |
| 三例合计耗时 | 7,242.0 ms | 8,022.7 ms | **+10.8%** |

逐例之后的卡片数为 **0 / 1 / 1**：第一例模型选择阶段总结，同时标记症状性质、部位、伴随表现的缺口，程序保留 `sufficient=false`；其余两例继续问。故题量下降部分来自提前整理阶段信息，不能用 −66.7% 直接证明必要问诊被更高效完成。已记录维度重问按规范化信息键机械计数，也不是医生对问题语义或必要性的判定。

原始证据为 `live-before.json`、`live-reviewed.json`，汇总为 `live-summary-reviewed.json`；最终汇总命令 exit 0，检查了所有预期 ID、失败与 usage 完整性。当前完整信息上下文增加输入 Token；本次输出也增加。没有完整流程成本、价格换算、重复试验或统计显著性证据，不能宣称更快、更便宜。

期间真实探测发现模型返回 `source=collected_info/answer` 与对象形式 `needs_more_info`，造成初次兼容失败。已修正合法来源枚举、出处校验和缺口兼容转换，并补非法对象拒绝测试。早期失败及中间结果均保留为 `live-after*.json`，最终报告使用最终源码的 `live-reviewed.json`，没有选取最漂亮的一次。固定重放早期配置导入错误和观察字段修正也保留在旧比较目录。

## 效果判断与剩余边界

上述历史结果仅说明部分控制约束和来源选择机制生效。预算停止、阶段缺口及仅展示已引用来源的处理不能作为改善，已经由 2026-10-03 修复取代。**仍未证明的指标**：完整问诊总轮数、漏问率、真实知识库与外部搜索排序质量、临床充分性；历史真实模型成本/耗时上升。

仍有三项实际取舍：不同原话采用保守冲突判断，互补描述也可能触发核对；词匹配回退不能等同语义相关，跨语言无法评估的来源排后并标注待核对；检索后的统一重排可能增加调用和等待，0.25 阈值需要真实语料校准。阶段总结的补充入口沿用追问，不自动重写原报告。

后续若要证明整体更有效，应在隔离测试数据上做完整多轮对照，并由专业评审记录必要维度漏问、未知/冲突保留、重复率、有效来源支持率及全流程 Token/延迟。本轮没有把这些待验证目标计为已完成收益。
